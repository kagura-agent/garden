## 养护要点

| 项目 | 要求 |
|------|------|
| ☀️ 光照 | 全日照，阳台最晒的位置 |
| 💧 浇水 | 自动吸水盆（Telsly 1.2L 懒人盆），保持下层有水即可，偶尔空一两天透气 |
| 🌡️ 温度 | 喜暖，冬天 5°C 以下搬进室内 |
| ✂️ 修剪 | 花谢后连下面两片叶子一起剪 |
| 🧪 施肥 | 花期半月一次，薄肥勤施 |
| 🐛 防虫 | 注意蚜虫和红蜘蛛 |

## 挑选记录

Luna 在盒马线下挑选，Kagura 远程指导：
- 选了分枝多、花苞密、枝干粗壮的一盆
- 主干粗 + 多分枝 + 花苞饱满 = 最优解

## 位置

📍 室内阳台（不会淋雨）

## 花盆

- **类型**: Telsly 自动吸水盆（懒人盆）
- **容量**: 1.2L 储水槽
- **原理**: 棉芯从下层吸水上来，土干了自动补水
- **加水方式**: 往下层储水槽加水，侧面透明窗口看水位
- **注意**: 水位不要超过透明窗口；偶尔让储水槽空1-2天让根系透气
