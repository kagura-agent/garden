# 🌿 花园管理原则

## 核心原则

**先收集，再建议。** 不凭通用知识猜测，每盆花的实际情况（盆、土、位置、光照）决定养护方式。

## 新植物入住流程

每次新植物到家，**先采集以下信息再建档**：

1. 🏷️ **标签/说明卡** — 品种、商家养护提示
2. 🪴 **花盆** — 类型、材质、特殊机制（懒人盆/自吸水/普通排水）
3. 🌱 **整株状态** — 全景照
4. 🔍 **土面/根部细节** — 土壤类型、覆盖物
5. 📍 **摆放位置** — 室内/室外、光照条件、是否淋得到雨

全部收集完 → 建 profile.md → 开始养护建议。

## 日常养护

- 每天提醒前**先读该植物的 profile.md**，根据盆型、位置给具体建议
- 不要因为室外下雨就建议室内植物不浇水
- 不同盆型浇水方式完全不同（普通盆浇透 vs 懒人盆看水位）
- 观察到新情况 → 更新 profile.md + 记录到 log.md
