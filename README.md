## 新植物入住流程

每次新植物到家，**先采集信息再给建议**：

1. 🏷️ **拍标签/说明卡** — 品种、商家养护提示
2. 🪴 **拍花盆** — 类型、材质、有无特殊机制（懒人盆/自吸水等）
3. 🌱 **拍整株状态** — 全景照
4. 🔍 **拍土面/根部细节** — 土壤类型、覆盖物
5. 📍 **确认摆放位置** — 室内/室外、光照条件

全部收集完再建 profile.md，不凭通用知识猜测。
